# CLAUDE.md — Agent Instructions for weave-rybbit-analytics

## What This Is

A lightweight WordPress plugin that adds Rybbit Analytics tracking to client
sites with Nginx proxy support and Gravity Forms event tracking. Built for
Weave Digital Studio / HumanKind Funeral Websites.

This is an internal plugin — NOT on wordpress.org. Updates are delivered via
a custom GitHub updater class.

## Architecture

- **PHP**: Namespaced functions in `inc/`, not classes (exception: GitHub updater)
- **JS**: React with `@wordpress/components` for the settings page only
- **Build**: `@wordpress/scripts` with a single webpack entry for settings
- **Settings**: `register_setting` with `show_in_rest` — React reads/writes via `/wp/v2/settings`
- **Admin UI**: Only `@wordpress/components` — no custom CSS, no HTML forms
- **No CPT, no blocks, no DataViews, no Interactivity API, no shortcodes**

### Data Flow

```
register_setting (inc/settings-page.php)
    ↓
WordPress REST API (/wp/v2/settings)
    ↓
React settings UI (src/js/settings/)        → admin configuration
get_settings() (inc/tracking-script.php)     → frontend <script> tag
get_settings() (inc/gravity-forms.php)       → GF event tracking
```

## Key Files to Modify

| Task | Files to Edit |
|------|---------------|
| Change settings fields | `inc/settings-page.php`, matching tab in `src/js/settings/components/` |
| Change tracking output | `inc/tracking-script.php` |
| Change GF integration | `inc/gravity-forms.php` |
| Update GitHub updater | `inc/github-updater.php` — constants at top of class |
| Add new settings tab | `src/js/settings/components/SettingsApp.js` + new tab component |

## Settings

All stored in a single serialised option: `weave_rybbit_settings`

| Key | Type | Default |
|-----|------|---------|
| `site_id` | string | `''` |
| `instance_url` | string | `https://app.rybbit.io` |
| `proxy_enabled` | boolean | `false` |
| `proxy_path` | string | `/ry` |
| `disable_for_admins` | boolean | `true` |
| `disable_for_logged_in` | boolean | `false` |
| `script_loading` | string | `async` |
| `gf_enable` | boolean | `false` |
| `gf_event_name` | string | `form_submission` |
| `gf_include_title` | boolean | `true` |
| `gf_include_id` | boolean | `true` |
| `gf_tracked_forms` | string | `''` |

## Build & Release

```bash
npm run build    # Build settings page JS
npm run start    # Watch mode
npm run lint     # Lint JS
```

### Creating a Release
1. Bump version in `weave-rybbit-analytics.php` header and `package.json`
2. Update `CHANGELOG.md`
3. Commit: `git commit -am "Release v1.x.x"`
4. Tag: `git tag -a v1.x.x -m "Version 1.x.x"`
5. Push: `git push origin main --tags`
6. GitHub Actions creates the release automatically

## Coding Conventions

- **PHP prefix**: `weave_rybbit_` for functions, `WeaveRybbitAnalytics\` for namespaces
- **Language**: NZ English (organised, colour, licence, centre, optimised)
- **Standards**: WordPress Coding Standards (tabs, spaces inside parentheses, short arrays)
- **Escaping**: Always. `esc_html()`, `esc_attr()`, `esc_url()`, `wp_kses_post()`
- **Text domain**: `weave-rybbit-analytics`
- **Licence**: GPL-2.0-or-later
- **PHP minimum**: 8.1 — `declare(strict_types=1)` in all files
- **WordPress minimum**: 6.2
- **Dependencies**: No ACF, no WooCommerce, no Composer, no jQuery
